## 🚀 Quick Start (Local Development)

### 1. Clone the repository
```bash
git clone https://github.com/your-username/ansh-bridal-mehandi-art.git
cd ansh-bridal-mehandi-art
```

### 2. Install dependencies
```bash
npm install
```

### 3. Start development server
```bash
npm run dev
```
Open your browser at `http://localhost:3000` (or `http://localhost:5173`).

### 4. Build for production
```bash
npm run build
```
The compiled, optimized output will be in the `dist/` directory, ready to deploy.

## 🌐 How to Publish on GitHub

### Option A: Push to a New GitHub Repository
1. Initialize git locally (if not already done):
   ```bash
   git init
   git add .
   git commit -m "Initial commit: Ansh Bridal Mehandi Art website"
   ```
2. Create a new repository on [GitHub](https://github.com/new) named `ansh-bridal-mehandi-art`.
3. Link your remote repository and push:
   ```bash
   git branch -M main
   git remote add origin https://github.com/your-username/ansh-bridal-mehandi-art.git
   git push -u origin main
   ```

### Option B: Deploy Free with GitHub Pages
1. Install `gh-pages` (optional) or use the automated GitHub Actions workflow included in `.github/workflows/deploy.yml`.
2. In your GitHub repository:
   - Go to **Settings** → **Pages**
   - Under **Build and deployment** → **Source**, select **GitHub Actions**.
   - Every push to `main` will automatically build and publish your site!

### Option C: 1-Click Deploy on Vercel or Netlify
- Import your GitHub repository into **Vercel** or **Netlify**.
- Build command: `npm run build`
- Output directory: `dist`
- Your site will be live on a custom HTTPS domain with instant global CDN!
